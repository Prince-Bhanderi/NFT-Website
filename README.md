# 🖼️ NFT Marketplace (OpenSea Clone)

A responsive NFT marketplace website inspired by OpenSea. Explore trending NFTs, browse categories, check top collections, connect wallets, and mint your own NFTs.

🔗 **Live Demo:** https://prince-bhanderi.github.io/NFT-Website/

## Features
- Hero section with live-style NFT stats (collectibles, auctions, artists)
- Notable Drops showcase
- "Create and sell your NFTs" step guide (wallet → upload → list)
- Browse by category (Art, Music, Photography, Sports, Trading Cards, Virtual Worlds, etc.)
- Top Collections ranking (24hr stats, floor price, % change)
- Embedded YouTube video section
- Wallet connect options (MetaMask, Bitski, Fortmatic, WalletConnect, Coinbase Wallet, Arkane)
- Newsletter subscribe footer
- Fully responsive layout
- Smooth animations (WOW.js, Animate.css)
- Owl Carousel / Slick slider support

## Pages
| Page | Description |
|------|-------------|
| `index.html` | Home page — marketplace overview, drops, rankings |
| `create.html` | Create your own NFT |
| `profile.html` | User profile page |
| `wallet.html` | Wallet connection page |
| `help.html` | Help centre / support |

## How to Run
1. Clone the repo:
   ```
   git clone https://github.com/prince-bhanderi/NFT-Website.git
   ```
2. Go into the folder:
   ```
   cd NFT-Website
   ```
3. Open `index.html` in your browser — that's it.

## Usage
- Browse NFTs, drops, and categories on the home page.
- Check **Top Collections** for trending floor prices.
- Click **Create** to mint a new NFT.
- Click the wallet icon to connect your crypto wallet.
- Click the profile icon to view your account.
- Visit **Help Centre** for support.
